Grounded retrieves the exact passages from a corpus and answers with a verbatim citation on every claim. When the documents do not support an answer, it says so instead of guessing.

The method

Three rules that make an answer trustworthy.

A raw model will confidently invent a number it does not know. Grounded is built so that cannot happen quietly.

01

Retrieve

Hybrid search, dense embeddings for meaning fused with BM25 keyword search for exact figures, finds the passages that actually answer the question.

02

Ground

The model answers only from those passages and attaches a verbatim citation to every claim, so each answer is checkable against its source.

03

Refuse

If the context does not support an answer, it returns a calibrated "I do not know" at zero confidence rather than hallucinating.

Request lifecycle

From question to cited answer.

STEP 01

Guard

The question is scanned for prompt injection and PII before it reaches the model.

STEP 02

Retrieve

Dense and BM25 rankings are merged with Reciprocal Rank Fusion, then optionally reranked.

STEP 03

Answer

A constrained model returns a typed object with citations, a refusal flag, and a confidence.

STEP 04

Verify

An evaluation harness scores faithfulness and retrieval recall, and gates regressions in CI.

The differentiator

Not a demo that looks right. A system whose quality is measured.

Every change is scored against a golden set on retrieval and generation quality. A regression gate fails the build if any metric drops, so the assistant cannot get quietly worse.
