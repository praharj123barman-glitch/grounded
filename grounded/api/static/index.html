Grounded reads a corpus, retrieves the exact passages, and answers with citations. When the documents do not support an answer, it says so instead of guessing.

01

Retrieve

Hybrid search (keyword + semantic) with reranking finds the passages that actually answer the question.

02

Ground

The model answers only from those passages, and attaches a verbatim citation to every claim.

03

Refuse

If the context does not support an answer, it returns a confident "I do not know" rather than hallucinating.
